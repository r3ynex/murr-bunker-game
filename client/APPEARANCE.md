# Оформление Windows-клиента

В распакованном архиве Windows файлы `theme.json` и `layout.json` лежат рядом с `Murr-Bunker.exe`. Для запуска через `cargo run` скопируй их рядом с собранным EXE, обычно в `client/target/debug`. Точный путь показан в настройках игры.

1. Открой любой из двух файлов в текстовом редакторе. Сохраняй в UTF-8.
2. Измени нужные значения и сохрани файл.
3. Нажми **Ctrl+Shift+R** на любом экране или **Настройки → Перезагрузить оформление** в главном меню. Пересборка и перезапуск игры не нужны.

Можно оставить в файле только изменённые ключи. Удаление файла или замена его на `{}` возвращает встроенные значения. При ошибке JSON, неизвестном ключе или недопустимом значении клиент использует встроенные значения для этого файла и показывает причину во всплывающем уведомлении слева снизу. Второй файл загружается независимо.

## theme.json

- `palette` — цвета в формате `[красный, зелёный, синий]`, целые числа от 0 до 255. `accent` управляет акцентными кнопками и выделением, `accent_text` — текстом акцентных кнопок.
- `fonts` — размеры текста от 8 до 48 логических точек egui. `family` принимает `"manrope"` (из `Manrope.zip` рядом с EXE или установленных шрифтов Windows, затем из EXE) и `"builtin"` (встроенные шрифты egui). Для своего шрифта создай папку `fonts` рядом с EXE, положи в неё, например, `MyFont.ttf` и укажи `"file": "MyFont.ttf"`. При недоступном или повреждённом файле используется выбранное семейство, при отсутствии внешнего Manrope — Manrope из EXE. Для сброса своего шрифта укажи `"file": null`.
- `buttons` — размеры кнопок `[ширина, высота]`, внутренние отступы `[по горизонтали, по вертикали]` и радиус скругления.
- `spacing` — расстояние между элементами, отступ после заголовка и интервалы вокруг разделителей.
- `icons` — текстовые значки на кнопках меню, в навигации, досье и таблицах. Выбирай символы, которые есть в шрифте. Пустая строка скрывает значок или выводит подпись действия. Порядок шести значков `navigation` соответствует разделам «Катаклизм», «Бункер», «События», «Досье», «Игроки», «Спецвозможности».

Например, этот `theme.json` меняет цвет и добавляет символ на кнопку создания игры.

```json
{
  "palette": { "accent": [104, 185, 240] },
  "icons": { "create": "+" }
}
```

**Manrope** использует четыре начертания из макета — Regular, Medium, SemiBold и Bold. Настройки `fonts` содержат отдельные размеры для заголовков, никнеймов, полей, досье и таблиц. Значения переведены в точки egui в масштабе 2/3 с учётом масштаба текстового слоя. Если выбран один пользовательский TTF, он используется для всех начертаний.

## layout.json

- `window_size` — размер окна. При перезагрузке клиент запрашивает новый размер, если значение изменилось.
- `content_margin`, `status_margin`, `panel_padding` — отступы основного экрана, всплывающего уведомления от нижнего края и панели бункера.
- `menu_top_fraction` — доля высоты над главным меню (от 0 до 0,5). `welcome_name_width` — ширина поля ника. `dialog_width` — ширина диалога создания комнаты.
- `lobby_columns`, `avatar_picker_columns`, `dossier_columns` — количество колонок. `lobby_avatar_size` и `avatar_picker_size` — размер аватаров.
- `hero_height`, `hero_inset`, `hero_top_gap`, `hero_text_size` — высота блока катаклизма, поля, отступ сверху и размер области текста.
- `dossier_padding` — внутренние отступы карточек. `players_cell_size` и `abilities_cell_size` — размеры ячеек двух игровых таблиц, обе прокручиваются по горизонтали.

Размеры указаны в логических точках egui. `welcome_top_fraction` и `menu_top_fraction` задают вертикальное положение входа и меню. `entry_button_size` — сторона квадрата кнопки входа, `profile_avatar_size` — сторона аватара в меню, `menu_profile_gap` — расстояние от профиля до кнопок, `section_min_height` — базовая высота игровых секций.

## Свои PNG-иконки

В архиве рядом с EXE есть папка `icons` с готовыми заглушками. Замени нужные файлы, сохрани их имена и нажми **Ctrl+Shift+R**. Используй PNG с прозрачностью, до 512×512 и до 1 МиБ на файл. Непрочитанный файл заменяется текстовым значком. Аватары по-прежнему берутся из папки `avatars`.

| Файл | Где используется |
| --- | --- |
| `login-continue.png` | Вход после выбора ника и аватара |
| `join-submit.png` | Подтверждение кода комнаты |
| `nav-catastrophe.png` | Катаклизм |
| `nav-bunker.png` | Информация о бункере |
| `nav-events.png` | События |
| `nav-dossier.png` | Личное досье |
| `nav-players.png` | Таблица игроков |
| `nav-abilities.png` | Таблица спецвозможностей |
| `lobby-host.png` | Отметка ведущего |
| `card-locked.png`, `card-unlocked.png` | Закрытая и раскрытая карточка |
| `card-edit.png` | Редактирование карточки ведущим |

Геометрия по умолчанию снята с артбордов PhotoCraft в масштабе около 2/3. В сборку встроены фон катаклизма и иллюстрация бункера, экспортированные из отдельных слоёв `unkerUI.pcraft`. Фон катаклизма загружается из ZIP-пака комнаты, если там есть `assets/catastrophe.png` (также поддерживаются JPG и WebP). При отсутствии изображения используется встроенный фон. Высота секции по умолчанию составляет 1000 логических точек egui. Статические начертания получены из [Manrope от Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope) с помощью FontTools. Текст лицензии поставляется в архиве.

Если рядом с обновлённым EXE остались полные `theme.json` и `layout.json` от предыдущей версии, сохрани их копию и возьми свежие файлы из архива. Старые значения имеют приоритет над встроенными и сохраняют прежние размеры и цвета.
