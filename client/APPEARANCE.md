# Оформление Windows-клиента

В распакованном архиве Windows файлы `theme.json` и `layout.json` лежат рядом с `Murr-Bunker.exe`. Для запуска через `cargo run` скопируй их рядом с собранным EXE, обычно в `client/target/debug`. Точный путь показан в настройках игры.

1. Открой любой из двух файлов в текстовом редакторе. Сохраняй в UTF-8.
2. Измени нужные значения и сохрани файл.
3. Нажми **Ctrl+Shift+R** на любом экране или **Настройки → Перезагрузить оформление** в главном меню. Пересборка и перезапуск игры не нужны.

Можно оставить в файле только изменённые ключи. Удаление файла или замена его на `{}` возвращает встроенные значения. При ошибке JSON, неизвестном ключе или недопустимом значении клиент использует встроенные значения для этого файла и показывает причину внизу окна. Второй файл загружается независимо.

## theme.json

- `palette` — цвета в формате `[красный, зелёный, синий]`, целые числа от 0 до 255. `accent` управляет акцентными кнопками и выделением, `accent_text` — текстом акцентных кнопок.
- `fonts` — размеры текста от 8 до 48 логических точек egui. `family` принимает `"manrope"` (из `Manrope.zip` рядом с EXE или установленных шрифтов Windows) и `"builtin"` (встроенные шрифты egui). Для своего шрифта создай папку `fonts` рядом с EXE, положи в неё, например, `MyFont.ttf` и укажи `"file": "MyFont.ttf"`. При недоступном или повреждённом файле используется выбранное семейство, при отсутствии Manrope — встроенные шрифты. Для сброса своего шрифта укажи `"file": null`.
- `buttons` — размеры кнопок `[ширина, высота]`, внутренние отступы `[по горизонтали, по вертикали]` и радиус скругления.
- `spacing` — расстояние между элементами, отступ после заголовка и интервалы вокруг разделителей.
- `icons` — текстовые значки на кнопках меню, в навигации, досье и таблицах. Выбирай символы, которые есть в шрифте. Пустая строка скрывает значок или выводит подпись действия. Порядок шести значков `navigation` соответствует разделам «Катаклизм», «Бункер», «События», «Досье», «Игроки», «Спецвозможности».

Например, этот `theme.json` меняет цвет и добавляет символ на кнопку создания игры.

```json
{
  "palette": { "accent": [104, 185, 240] },
  "icons": { "create": "+" }
}
```

## layout.json

- `window_size` — размер окна. При перезагрузке клиент запрашивает новый размер, если значение изменилось.
- `content_margin`, `status_margin`, `panel_padding` — отступы основного экрана, нижней строки и панели бункера.
- `menu_top_fraction` — доля высоты над главным меню (от 0 до 0,5). `welcome_name_width` — ширина поля ника. `dialog_width` — ширина диалога создания комнаты.
- `lobby_columns`, `avatar_picker_columns`, `dossier_columns` — количество колонок. `lobby_avatar_size` и `avatar_picker_size` — размер аватаров.
- `hero_height`, `hero_inset`, `hero_top_gap`, `hero_text_size` — высота блока катаклизма, поля, отступ сверху и размер области текста.
- `dossier_padding` — внутренние отступы карточек. `players_cell_size` и `abilities_cell_size` — размеры ячеек двух игровых таблиц, обе прокручиваются по горизонтали.

Размеры указаны в логических точках egui. Значения по умолчанию используют Manrope и цвета `#030303`, `#131313`, `#3D3D3D`, `#EC8915` из слоёв макета PhotoCraft. Ширина кнопок меню адаптирована из 368 единиц макета к 184 логическим точкам. Остальные размеры рассчитаны под существующую компоновку клиента.
