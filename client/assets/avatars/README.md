# Свои аватарки для Murr Бункера

Вместо двенадцати временных цветных значков клиент показывает твои картинки, если находит их в папке `avatars`.

## Для готовой Windows-сборки

Рядом с `Murr-Bunker.exe` создай папку `avatars`:

```text
Murr-Bunker.exe
Manrope.zip           (необязательно)
avatars/
  01.png
  02.png
  03.png
  ...
  12.png
```

Каждый файл соответствует одноимённому месту в окне выбора аватара. **Не нужно заполнять сразу все 12**: пустые места покажут стандартный цветной символ.

- Поддерживаются **PNG, JPG, JPEG и WebP** (например, `01.png` или `01.webp`).
- Рекомендуемая форма — квадрат, например **256 × 256** пикселей.
- Максимум **1024 × 1024** и **3 МБ** на файл.
- Имена строго из двух цифр: `01.png`, `02.png`, …, `12.png`.
- Перезапусти программу, чтобы новые изображения загрузились.

## При разработке в GitHub

Положи картинки в `client/assets/avatars/` и закоммить изменения. Windows Actions автоматически скопирует их в папку `avatars` сборки. Тогда все, кто скачает этот же ZIP с игрой, увидят одинаковые аватары.

**Важно:** сервер пока передаёт другим игрокам только **номер выбранного аватара**, не сам файл изображения. Поэтому для одинакового отображения у всех игроков должен быть **одинаковый набор картинок** в клиенте. Следующий этап — сделать доставку аватарок через игровые ресурсы/пак с сервера, как сделано для фонового изображения катаклизма.

Не используй чужие изображения для публичного релиза без соответствующих прав на них.
