# Свои аватарки для Murr Бункера

Клиент показывает пронумерованные картинки из папки `avatars`. Окно выбора прокручивается и подгружает изображения по мере прокрутки.

## Для готовой Windows-сборки

Рядом с `Murr-Bunker.exe` создай папку `avatars`:

```text
Murr-Bunker.exe
Manrope.zip           (необязательно)
avatars/
  01.png
  02.png
  13.jpg
  50.webp
```

Порядок в окне выбора определяется номером файла. Пропуски допустимы. Для номеров 1–12 без картинки отображаются стандартные цветные значки.

- Поддерживаются **PNG, JPG, JPEG и WebP** (например, `01.png` или `01.webp`).
- Рекомендуемая форма — квадрат, например **256 × 256** пикселей.
- Максимум **1024 × 1024** и **3 МБ** на файл.
- Название файла до точки — положительное целое число. `01.png` и `1.png` соответствуют одному аватару.
- Чтобы увидеть новые файлы, закрой и снова открой окно выбора аватара.

## При разработке в GitHub

Положи картинки в `client/assets/avatars/` и закоммить изменения. Windows Actions автоматически скопирует их в папку `avatars` сборки. Тогда все, кто скачает этот же ZIP с игрой, увидят одинаковые аватары.

В комнате сервер передаёт номер аватара. Чтобы все видели одну и ту же картинку, раздай игрокам одинаковую папку `avatars` или одну сборку. Если картинки у игрока нет, он увидит цветной значок. Для номеров выше 12 нужен обновлённый Worker.

Не используй чужие изображения для публичного релиза без соответствующих прав на них.
