# Murr Bunker Game

Портативный сетевой «Бункер» для игры с друзьями. Проект вдохновлён жанром социальной игры про выживание, но **механики, паки и интерфейс могут отличаться от оригинала**. Исходники содержат демонстрационный авторский контент.

**Статус:** ранняя играбельная версия. Windows UI по авторскому макету, игровые события и итоговый эпилог пока в разработке.

## Стек

- **Клиент:** Rust + egui/eframe, Windows EXE без установщика и без WebView2.
- **Сеть:** Cloudflare Worker + Durable Object на каждую комнату, WebSocket.
- **Сборка:** GitHub Actions → ZIP c `Murr-Bunker.exe`.
- **Паки:** один JSON-файл с логическими разделами `meta`, `roles`, `characteristics`, `items`, `world`, `customCategories`. Поддержка старого JSON и импорта Бункер Онлайн.

## Windows-интерфейс по авторскому макету

Новая итерация Windows-клиента включает приветствие, выбор аватара, главное меню, лобби с готовностью, катаклизм, бункер, досье, таблицы персонажей и ведущего. Незаконченные механики помечены WIP. Схема экранов, ZIP-паки с автоматической выдачей изображений и требования к безопасности описаны в **[UI_IMPLEMENTATION.md](UI_IMPLEMENTATION.md)**.

**Оформление:** цвета, шрифты, кнопки и размеры панелей настраиваются в `theme.json` и `layout.json` рядом с EXE. Перезагрузка в настройках или по **Ctrl+Shift+R**. [Инструкция по оформлению](client/APPEARANCE.md).

**Manrope:** шрифт включён в Windows-клиент. В `theme.json` можно выбрать встроенные шрифты egui или задать свой TTF. Веб-тестер загружает Manrope через Google Fonts.

**Свои аватарки:** помести файлы с числовыми именами, например `01.png`, `13.jpg` и `50.webp`, в папку `avatars` рядом с EXE и снова открой окно выбора. Подробности в **[инструкции по аватаркам](client/assets/avatars/README.md)**. Файлы из `client/assets/avatars/` автоматически попадают в Windows-сборку.

**Передача предметов:** ведущий открывает редактор раскрытой ячейки «Крупный инвентарь» или «Рюкзак», отмечает предметы или вводит их ID через запятую, выбирает получателя и нажимает «Передать выбранное». Предметы перемещаются в ту же категорию у получателя. Если его карточка закрыта, содержимое увидит только он, пока не раскроет её.

## Быстрый старт

1. Готовый клиент по умолчанию подключается к `https://murr-bunker-api.r3ynex-error.workers.dev`. Локально можно запустить `cd server && npm install && npm run dev` и выбрать `http://127.0.0.1:8787` в настройках. Старое значение `127.0.0.1` из конфигурации автоматически мигрирует на Cloudflare.
2. В папке `client`: `cargo run`. Либо скачай успешный Artifact сборки из **Actions → Build portable Windows client**.
3. Запусти два экземпляра клиента. Первый создаёт комнату, второй вводит восьмизначный код. Для проверки требуется **два игрока**.
4. Для интернета: `cd server && npx wrangler login && npm run deploy`; полученный адрес Worker укажи в клиенте и сохрани настройки.

**Примечание:** Actions собирает клиент, но не публикует Cloudflare Worker автоматически.

## Как создать собственный пак

Клиент показывает файлы JSON и ZIP из папки `packs` рядом с `Murr-Bunker.exe`. При обычном `cargo run` используется `packs/` в корне репозитория, если рядом с EXE такой папки нет. Чтобы добавить, заменить или удалить пак, достаточно поменять файлы и открыть настройки создания комнаты или нажать ↻. При первом запуске включается пак, чей `meta.id` указан в поле `default` файла `packs/.catalog.json`. Если такого пака нет, включается первый читаемый пак по имени файла.

Открой **[packs/starter.json](packs/starter.json)** — весь пак находится в одном файле, а карточки разделены на профессии и способности (`roles`), характеристики (`characteristics`), вещи (`items`) и мир (`world`). Отдельная секция `customCategories` позволяет вводить новые типы карточек. Не нужно создавать директории с десятками JSON.

Полный справочник, пример, проверка и конвертация экспортов Бункер Онлайн — **[PACK_FORMAT.md](PACK_FORMAT.md)**. При создании комнаты можно выбрать или перетащить JSON/ZIP из другой папки и включить нужные паки в списке. Активные паки объединяются. Карточки и сценарии берутся из всех активных паков. Фон берётся из пака выпавшего катаклизма. Ссылки на добавленные вручную файлы и переключатели сохраняются в `murr-packs.json` рядом с EXE. В лобби ведущий может заменить пак комнаты. Если комната создана без загрузки пака, сервер использует демонстрационные карточки.

## Тестирование с телефона без ПК

Мобильный временный интерфейс лежит в `web/`. Он запускается на **том же Cloudflare Worker**, что и сервер комнат. Чтобы разместить его без ПК, в GitHub добавь два Actions Secrets: `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN`, затем запусти **Actions → Deploy Cloudflare rooms and mobile tester → Run workflow**. После успешного развёртывания открой выданную ссылку `.workers.dev` в браузере телефона. Голос отдельно в Discord.

**Каждую комнату подключать отдельно не надо:** Cloudflare создаёт её автоматически при нажатии «Создать комнату». Подробные инструкции — [в руководстве](DEVELOPER_GUIDE.md#11-как-протестировать-игру-с-androidiphone-без-пк). API-ключ не отправляй никому и никогда не добавляй в код.
