# Murr Bunker Game

Нативная портативная игра «Бункер» с сетевыми комнатами на Cloudflare. Прототип в разработке.

## Архитектура
- **Rust + egui/eframe** — клиент Windows без установщика.
- **Cloudflare Worker + Durable Objects** — сетевые комнаты, авторитетное состояние и синхронизация.
- **GitHub Actions** — сборки исполняемого файла.

См. дальнейшие коммиты для исходников и инструкции запуска.
